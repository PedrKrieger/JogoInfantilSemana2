# Clube das Descobertas

Jogo de perguntas para crianças de 5 a 6 anos, feito para o projeto de Curricularização da Extensão 2026.1 da UNIFEBE.

São 20 perguntas sobre animais, cores, letras e números, com imagens do material da atividade. O jogo tem três dificuldades: fácil, médio e difícil. As alternativas mudam conforme o nível, mas a resposta certa continua a mesma. Também dá para personalizar o personagem.

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

Feito com HTML, CSS e JavaScript.
